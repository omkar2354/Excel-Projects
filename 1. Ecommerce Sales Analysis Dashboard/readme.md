# E-commerce Sales Analysis Dashboard

## 📌 Objective
To analyze overall sales, profit, and order trends in an e-commerce business.

## 🛠 Tools Used
- Excel
- Pivot Tables
- Charts

## 📊 Key Metrics
- Sales: $2.29M
- Profit: $286K
- Orders: 9994
- Profit Margin: 12.47%

## 📈 Insights
- Strong YoY growth in sales and profit
- Technology category contributed the highest profit
- Phones and Chairs are top-selling sub-categories
- Certain regions outperform others significantly

## 🚀 Outcome
Helps businesses identify profitable products and improve decision-making.
