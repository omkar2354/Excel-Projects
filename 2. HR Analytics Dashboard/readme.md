# HR Analytics Dashboard

## 📌 Objective
To analyze employee attrition and workforce trends.

## 📊 Key Metrics
- Total Employees: 1470
- Attrition: 237
- Attrition Rate: 16.12%
- Avg Age: 36.9

## 📈 Insights
- Majority attrition in Sales roles
- Highest attrition among Bachelor's degree holders
- Age group 25–34 shows highest attrition
- R&D department dominates workforce

## 🚀 Outcome
Helps HR teams improve retention strategies.
